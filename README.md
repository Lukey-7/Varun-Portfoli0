# Ghost Cyan Portfolio

A modern, interactive portfolio website showcasing my projects and skills. Built with cutting-edge web technologies.

## 🚀 Technologies

This project is built with:

- **Vite** - Next generation frontend tooling
- **TypeScript** - Type-safe JavaScript
- **React** - UI component library
- **shadcn-ui** - Beautiful, accessible components
- **Tailwind CSS** - Utility-first CSS framework

## 📦 Installation

Clone the repository and install dependencies:

```sh
# Clone the repository
git clone https://github.com/Lukey-7/ghost-cyan-portfolio.git

# Navigate to the project directory
cd ghost-cyan-portfolio

# Install dependencies
npm install

# Start the development server
npm run dev
```

## 🛠️ Development

Run the development server with hot module replacement:

```sh
npm run dev
```

The application will be available at `http://localhost:8080`

## 🔧 Available Scripts

- `npm run dev` - Start development server
- `npm run build` - Build for production
- `npm run preview` - Preview production build locally
- `npm run lint` - Run ESLint
- `npm test` - Run tests
- `npm run test:watch` - Run tests in watch mode
